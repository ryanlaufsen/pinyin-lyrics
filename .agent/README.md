# Agent Workspace

This directory keeps continuity material for future agent sessions.

- `scratch/CURRENT.md` is the active working notebook.
- `cache/index.md` is the committed cache manifest.
- `cache/artifacts/` is for local bulky outputs, logs, screenshots, generated reports, and temporary research exports.
- `templates/` holds reusable handoff and subagent report shapes.

Update the scratch file and devlog before handing off meaningful work.
